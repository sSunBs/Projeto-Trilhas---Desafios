## 🥇 Desafios Trilha

#### Desafio 1

- [x] Crie uma variável chamada nome e atribua seu nome a ela. Em seguida, exiba o valor dessa variável.

#### Desafio 2

- [x] Crie duas variáveis: uma chamada idade e outra chamada altura. Atribua a idade o valor 25 e a altura o valor 1.75. Exiba ambos os valores.

#### Desafio 3

- [x] Crie uma variável chamada preco com o valor 50 e uma variável desconto com o valor 0.2 (20%). Calcule o preço com desconto e exiba o valor final.

#### Desafio 4

- [x] Crie uma variável chamada temperatura e atribua o valor 30. Se a temperatura for maior que 25, exiba a mensagem "Está calor!". Caso contrário, exiba "Está fresco!".

#### Desafio 5

- [x] Crie uma variável idade e atribua um valor. Se a pessoa for maior de idade (18 ou mais), exiba "Você é maior de idade". Caso contrário, exiba "Você é menor de idade".

#### Desafio 6

- [x] Crie uma variável chamada nota e atribua um valor entre 0 e 10. Se a nota for maior ou igual a 7, exiba "Aprovado". Se for entre 5 e 6, exiba "Recuperação". Caso contrário, exiba "Reprovado".

#### Desafio 7

- [x] Crie duas variáveis, numero1 e numero2, e atribua valores a elas. Verifique se os dois números são iguais e, caso sejam, exiba "Os números são iguais". Caso contrário, exiba "Os números são diferentes".

#### Desafio 8

- [x] Crie uma variável chamada nome e uma variável chamada idade, Exiba a mensagem "Olá, meu nome é [nome] e eu tenho [idade] anos", utilizando concatenação.

#### Desafio 9

- [x] Cria um loop que imprima os número de 1 a 10 na tela.

#### Desafio 10 

- [x] Crie um loop que peça ao usuário para digitar um número até que ele digite o número 5.

#### Desafio 11

- [x] Crie um loop que imprima a tabuada do número 7, de 1 a 10.

#### Desafio 12

- [x] Crie um loop que exiba todos os números pares de 0 a 20.

#### Desafio 13

- [x] Escreva um código que calcule a área de um círculo. Utilize uma função para realizar o cálculo. A função deve receber o raio como parâmetro e retornar a área.
  
#### Desafio 14

- [x] Comente seu código explicando o que cada parte faz. Crie um programa simples que calcule a soma de dois números e imprima o resultado.
